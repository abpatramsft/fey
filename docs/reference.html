Reference

The deterministic surface area.

These commands read and write Fey’s repository-local artifacts. The skill tells Copilot when to use them; this reference explains what each one guarantees.

Invocation

Until the npm package is published, invoke the scripts through Node from the target repository:

current executable paths
node .github/skills/fey-create/bin/fey.js <command> .
node .github/skills/fey-improve/bin/fey-improve.js <command> .

The skill documentation often uses the shorter future-facing names fey and fey-improve. They refer to these same scripts.

Exit behavior

Validation and gate commands return zero when the requested invariant passes or deliberately has nothing to evaluate. They return non-zero with an actionable report when work is malformed, incomplete, out of scope, stale, or rejected.

commit-if-better returns non-zero for a rejected candidate and records that decision when the failure is a score delta or protected-criterion regression. A stale fingerprint or malformed gate is not recorded as a valid rejected experiment; fix it and record again.

Repository test

end-to-end disposable sample
node --test .github/skills/fey-improve/test/improve.test.js

The test creates a temporary git repository and exercises worktree isolation, lifecycle hooks, objective commands, accepted and rejected iterations, score tampering, rename scope escapes, secret detection, exact revert, dashboard readiness, finalization, and cleanup.
